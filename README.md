## A few things I've built

**Traffic stop search analysis (Random Forest + SHAP + Power BI + Streamlit)**  
Predicted vehicle search likelihood on 2.1M real traffic stops — Random Forest hit 
ROC-AUC 0.875 on a 13.5:1 imbalanced dataset. SHAP explainability surfaced the top 
drivers. Fairness audit found Hispanic and Black drivers searched at 1.65x and 1.57x 
the rate of White drivers, holding even when controlling for violation type. Deployed 
as a live Streamlit app with a 4-page Power BI dashboard.
